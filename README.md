# 月季花期生长可视化工具

面向鲜切花基地采收窗口推演的 3D 可视化应用：以积温（GDD）驱动月季从花苞到盛开的分级生长模型，
参数化曲面生成花瓣，WebGPU 优先渲染，200 支花枝实例化合批。

## 技术栈

- TypeScript + Vue 3（Composition API、`reactive` 集中状态）
- Babylon.js v7，**WebGPU 引擎优先**，不支持时自动回退 WebGL2
- Vite 6 构建

## 启动

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5180
npm run build      # 类型检查通过后的生产构建
npm run typecheck  # 仅类型检查
```

打开 `http://127.0.0.1:5180/?demo=1` 可进入演示模式（自动摆放 200 支花并推进到半开）。

## 功能与页面

### 积温页
- 日平均温、生物学零度、累积天数设置，自动计算日积温与累计 GDD
- 采收窗口按开放度阈值（默认 35%~70%）经单调三次样条**反查积温**，换算发育天数与日历日期
- 实时显示当前积温对应的开放度

### 品种页
- 花瓣参数化曲面：层数 5~9 可调、每层瓣数、瓣长/瓣宽、曲面细分
- 每片花瓣 4 个弯曲控制点 + 4 个卷边控制点（Catmull-Rom 样条）
- 花青素两端颜色（花苞深红 → 盛开浅粉），按开放度插值并以逐实例颜色上传
- 生长曲线 SVG 编辑器：拖动控制点、双击加点、表格精确输入；Fritsch–Carlson 单调三次样条保证开放度不回退
- 多品种管理（复制/删除），曲线或花瓣参数改动后**所有已放置花枝统一按新曲线重算形变并刷新着色**

### 布局 / 方案页
- 1~200 支花枝随机摆放（确定性种子，可复现），含积温偏移模拟分批定植
- 整枝模型：Catmull-Rom 轻微弯曲茎秆、3 片错落叶片、5 片随开放度外翻萼片
- JSON 方案导出/导入：完整保存积温设置、采收阈值、品种曲线控制点与花瓣参数、花枝布局、时间轴位置

### 时间轴
- 可拖动到任意积温节点，支持 0.5×~4× 速度回放整个花苞→盛开过程
- 琥珀色带标记采收窗口，绿色游标同步显示在生长曲线图上

## 生长模型

| 量 | 花苞（开放度 0） | 盛开（开放度 1） |
|---|---|---|
| 展开角（语义） | 15° | 120° |
| 几何倾斜角 | 15°（近直立抱合） | 82°（配合瓣尖反卷） |
| 花径缩放 | 0.38 | 1.0 |
| 着色 | 深红 | 浅粉 |
| 萼片 | 向上托合 | 外翻至 110° |

内层花瓣带开放滞后，形成由外向内的开放次序；瓣尖反卷量按开放度烘焙进 LOD 曲面。

## 渲染管线

- 花瓣按开放度分为 **8 个 LOD 分档**，每档一套细分递减的参数化曲面
- 同档全部花瓣（200 支约 1 万实例）合并为一个 **Thin Instance 薄实例网格**，逐实例矩阵 + `instanceColor`
- 茎段、叶片、萼片同样薄实例合批；整场景个位数 Draw Call（实测 200 支 / 1 万花瓣实例 = 7 次绘制调用）

## 自动化验证

```bash
node scripts/smoke.cjs                      # 200 支大田全流程（时间轴/LOD/JSON 回路）
SMOKE_SINGLE=1 SMOKE_STAGE=bud node scripts/smoke.cjs   # 花苞阶段
SMOKE_SINGLE=1 SMOKE_STAGE=mid node scripts/smoke.cjs   # 半开阶段
SMOKE_SINGLE=1 SMOKE_STAGE=full node scripts/smoke.cjs  # 盛开阶段
```

测试通过 Chrome DevTools Protocol 驱动无头浏览器，断言控制台零错误、LOD 分档实例数、
Draw Call 统计以及 JSON 导出→清空→导入的数据还原，并输出截图 `scripts/smoke-shot.png`。

## 目录结构

```
src/
  core/        数学库（单调样条/Catmull-Rom）、参数化花瓣曲面、生长模型、品种数据
  scene/       SceneManager：WebGPU 引擎、薄实例合批、LOD、茎秆叶片
  components/  积温页/品种页/布局页/时间轴/3D 视口/SVG 曲线编辑器
  store.ts     响应式状态与全部操作 action
  types.ts     领域类型与常量
```
