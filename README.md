# 编组站调车作业仿真器

基于 **TypeScript + React + three.js** 的铁路编组站三维调车作业仿真。在浏览器内构建包含到达场、牵出线、梯线道岔群、分类线与出发线的完整站场，支持 300 节车辆同时在场的实时调车仿真。

## 功能清单

| 需求 | 实现 |
| --- | --- |
| 三维站场（股道/道岔/车辆模型） | `InstancedMesh` 实例化渲染，钢轨、枕木、道岔标记、车辆单体模型 |
| 调车计划面板 | 4 类内置计划（解体/编组/整理/超限取送），作业钩可拖动 |
| 拖放车辆到目标股道 | HTML5 拖放 + 射线投影到地面，最近边反查股道 |
| 沿道岔路径生成轨迹 | 网络拓扑 Dijkstra 寻路，道岔开通位置约束，折线采样轨迹 |
| 连挂/解钩判定 | 0.3m 阈值连挂，自动合并车列并对齐车钩；解钩拆分后段沿原路径滑行 |
| 300 车辆同场 | 单步仿真 ~1.3ms（预算 16.6ms），车辆/枕木/占用块全部实例化，draw call 个位/十位数 |
| 股道占用区半透明色块 | `InstancedMesh` + `depthWrite:false` + `renderOrder`，靠深度缓冲与车辆正确遮挡，无穿插闪烁 |
| 道岔切换联动重算 | 切换即重算受影响车列路径与 ETA，实测 <0.1ms（要求 200ms 内） |
| 车列合并/车钩对齐 | 连挂后沿轨迹弧长按精确车长重排，停留车列相邻车中心距误差 ≤0.5m |
| 解钩后段滑行 | 继承原轨迹、阻力减速、到停留位停车 |
| 限界检查视图 | 建筑限界线框沿线路拉伸 + 车辆轮廓 SVG 截面，超限车红色描边 |
| 缩放/旋转/跟随 | OrbitControls + 选中车辆平滑跟随镜头 |
| 浏览器内持久化 | localStorage 保存站场与计划 |
| 导出/导入站场文件 | JSON 导出分享、导入校验 |
| 60fps（>200 车） | 仿真与渲染解耦，React UI 仅 4Hz 取快照，仿真循环不触发 React 重渲染 |

## 快速开始

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm run test:smoke # 无头仿真冒烟测试（寻路/连挂/解钩/重算/性能）
```

## 架构

```
src/
├── types.ts              # 领域模型与常量（0.3m 阈值、200ms 重算预算等）
├── sim/
│   ├── geometry.ts       # 折线采样、弧长、运动学工具
│   ├── network.ts        # 站场网络拓扑：邻接表、道岔约束 Dijkstra、轨迹采样
│   ├── yardGenerator.ts  # 程序化站场（17 道岔、17 股道、300 车、4 计划）
│   ├── engine.ts         # 仿真引擎：车列运动、连挂/解钩、进路开通、占用区、限界、ETA
│   ├── renderer.ts       # three.js 场景：实例化渲染、拾取、限界线框、镜头跟随
│   ├── store.ts          # RAF 循环 + React 桥（4Hz 快照）
│   └── storage.ts        # localStorage 与 JSON 导入导出
├── components/
│   ├── PlanPanel.tsx     # 左：调车计划与作业钩（拖放源）
│   ├── Viewport.tsx      # 中：三维视口（拖放目标、HUD、视角控制）
│   └── RightPanel.tsx    # 右：车辆列表、限界截面、道岔控制、事件、性能
└── App.tsx               # 装配与全局操作
```

### 关键设计

- **网络拓扑寻路**：节点/边/道岔图。道岔是单点设备，仅从 root 出发时按开通位置过滤；`findRoute` 在忽略当前道岔位置下求拓扑最短路并给出所需道岔状态，`openRoute` 自动扳动道岔开通进路，被搬动的道岔联动触发其他在途车列重算。
- **轨迹与车列**：每条轨迹在起点前预铺一段跨边"车尾延伸段"，使长车列所有车辆都能在非负里程上采样；世界位置为唯一真值，边 offset 由折线最近点投影反算。
- **深度排序**：占用色块透明材质 `depthWrite:false`、`renderOrder=10`，不透明车辆先写入深度缓冲，色块靠深度测试正确遮挡，彻底避免透明穿插闪烁。
- **性能**：车辆车体/车顶/超限描边/占用块/枕木均为 `InstancedMesh`；轨迹线几何按签名缓存仅在路径变化时重建。

## 操作指南

1. 左侧选择调车计划，点「执行计划」自动按钩排队，或把单个作业钩拖到三维视图的股道上手动指定目标。
2. 右侧车辆列表的车辆也可直接拖到三维股道；点击车辆选中并跟随。
3. 右侧道岔控制可手动切换道岔，观察在途车列路径与 ETA 联动重算。
4. 打开「限界检查视图」查看建筑限界线框，选中车辆查看截面轮廓与超限标注。
5. 顶栏保存/导出/导入站场 JSON，或重建 100/200/300 车场景做压力测试。
