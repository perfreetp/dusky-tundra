# 电梯困人救援空间定位工具

TypeScript + Svelte + Babylon.js(WebGPU 优先,自动回退 WebGL2)。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
npm run check    # 类型检查
```

## 功能

- **模型载入**:载入井道 / 轿厢 glTF(.glb/.gltf)模型,未载入时使用内置参数化模型;模型文件存入 IndexedDB,刷新后自动恢复。
- **故障点标注**:切到「标注故障点」模式,在三维场景中点击模型表面,自动生成带引线的空间标注,内容含楼层、部件名、三维坐标。
- **半透明轿厢**:开启后半透明化井道壁 / 导轨 / 轿厢三层结构(深度预通道 + 距离排序 + OIT,保证近处遮远处、叠加不串色),可透过轿厢看到内部被困人员标记。
- **层高滑块**:拖动改变轿厢停靠楼层,依附轿厢的标注与被困点随轿厢联动移动并保持贴附。
- **剖显模式**:沿井道纵向剖开只显示一半结构,被剖掉一侧的标注引线自动缩短到剖切可见面(虚线显示)。
- **被困点**:可放置多个,每个点带朝向指示(圆形箭头牌 billboard 始终朝向相机,地面锥形箭头指示面对方向)。
- **定位清单**:右侧面板按楼层分组,点击条目相机飞向该点;支持备注编辑与删除。
- **持久化与分享**:标注 / 被困点 / 轿厢楼层 / 开关状态存 localStorage,模型存 IndexedDB;「导出定位结果」生成 JSON 文件分享,可再导入。

## 目录

- `src/lib/engine.ts` — Babylon 场景管理(引擎、模型、透明排序、剖切、拾取、标注/人员实体、相机飞行)
- `src/lib/store.ts` / `persistence.ts` / `exchange.ts` — 状态、浏览器持久化、导入导出
- `src/components/` — 工具栏、覆盖层标注(引线 + 标签)、右侧清单
