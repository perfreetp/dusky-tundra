# 候梯厅客流疏散推演工具

基于 PixiJS + pixi-viewport + React + TypeScript 的候梯厅客流疏散推演工具。

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建
```

## 使用流程

1. **铺设平面**:左侧工具栏选择「楼层平面」拖拽铺设可行走区域(可多个矩形拼接),用「候梯区」「电梯厅」「楼梯口」框出对应区域。
2. **放置客流源**:选「客流源」在入口处点击放置;选中后在右侧面板设置到达速率(人/秒)与总人数。
3. **配置推演**:右侧面板设置当前楼层、建筑层数、停靠策略(全部/单双层/分区)、电梯往返时间、开门停靠时间、密度阈值。选中电梯可改额定载重。
4. **播放推演**:底部时间轴播放/暂停、倍速,拖动滑块可回看任意时刻的密度与排队长度(热力按该时刻快照重建)。

## 功能说明

- **导航**:平面栅格化为 0.5m 导航网格,对每个电梯/楼梯做 BFS 距离场;个体走向"最近可用"目标(距离 + 排队长度折算),每 2 秒重新选路。
- **热力图**:密度分五档着色(蓝→绿→黄→橙→红),超过密度阈值的位置叠加红色脉冲圈;热力网格随视口缩放重采样,避免块状。
- **电梯**:按额定载重与停靠层逐层装载(每人 0.8s),装载后个体从平面消失;轿厢标签实时显示已载人数与运行状态(停/行/不停)。
- **重算对比**:改动电梯数量、载重或停靠策略后整段推演自动重算;重算期间旧结果保留显示,重算完成后可勾选「对比上一次结果」叠加查看旧个体分布与旧统计。
- **统计**:右侧面板列出各电梯累计载客与平均等待,点击表格行高亮该电梯的服务范围。
- **导出分享**:工具栏「导出文件」把平面、配置与完整推演结果(含逐时刻快照)打包为 JSON;「导入文件」可还原。
- **视口**:滚轮缩放、拖拽平移(选择工具下)。

## 引擎冒烟测试

```bash
npx esbuild test/engine.smoke.ts --bundle --format=esm --outfile=test/.smoke.mjs && node test/.smoke.mjs
```

验证疏散人数守恒、结果确定性(同配置两次一致)、策略变更后重算正确。

## 目录结构

```
src/
  model/types.ts     数据模型与停靠策略
  model/navgrid.ts   导航网格 + BFS 距离场
  model/demo.ts      示例平面
  sim/engine.ts      确定性推演引擎(输出逐时刻快照)
  components/
    PixiStage.tsx    Pixi 画布:绘制编辑、个体、热力图、脉冲圈、服务范围
    Toolbar.tsx      左侧工具栏
    RightPanel.tsx   右侧属性/配置/统计面板
    Timeline.tsx     底部时间轴
  utils/export.ts    导出/导入
```
