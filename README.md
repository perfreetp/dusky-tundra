# 车架碰撞变形与应力可视化工具

基于 **Vue 3 + TypeScript + three.js + manifold-3d** 的车架碰撞塑性变形与应力分布可视化应用。

## 运行

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 生产构建(dist/)
npm run preview  # 预览构建产物
```

## 使用流程(按侧栏 ① → ④ 顺序)

1. **车架导入与材料分区**
   - 导入 STL / OBJ / GLTF / GLB 网格,或点击「加载示例车架」——示例车架由 manifold-3d 布尔运算生成(中空外壳 + 内部梁并集,`refineToLength` 细分)。
   - 按车架 X 向区间划分材料分区,逐区设置屈服强度(MPa),可勾选「分区着色预览」。
2. **碰撞施加与变形计算**
   - 在 6 个预设碰撞方向(正碰 / 追尾 / 左右侧碰 / 顶压 / 托底)间切换,调节冲量(kN·s)。
   - 点击「施加碰撞」:对同一车架可重复施加,塑性位移逐次累积,应力取历史最大值。
3. **应力着色与剖切对比**
   - 应力按蓝→青→绿→黄→红渐变实时着色,色标上限可自动或手动。
   - 「叠加原始车架」进入变形前后对比模式;启用剖切平面后可沿 X/Y/Z 轴拖拽(视口中直接拖橙色平面或用滑块),查看内部梁弯曲。
4. **变形网格导出**
   - 导出变形后网格(STL / OBJ)、每顶点应力数据(CSV)、碰撞报告(JSON)。

右侧栏实时显示:顶点/三角面数、碰撞次数、初始/当前体积与体积变化率、最大应力值及其空间坐标与所在分区、超屈服顶点数、单次重算耗时。

## 技术要点

- **变形模型**(Web Worker,`src/workers/deform.worker.ts`):以冲击方向最极端顶点为撞击参考点,应力场按沿程指数衰减 × 横向高斯衰减分布;应力超过所属分区屈服强度的部分按塑性硬化模量转化为永久位移,再经两轮拉普拉斯平滑模拟结构连续性。几何与应力在 Worker 中累积,切换碰撞角度后增量重算。
- **性能**:20 万顶点级网格单次碰撞重算约 75 ms(实测,含平滑与体积重算),通过 Transferable 数组与主线程零拷贝更新 BufferAttribute。
- **遮挡**:内部梁不透明先渲染写深度,外壳半透明(`depthWrite: false`,高 renderOrder)后渲染,保证叠加显示时深度正确。
- **体积**:散度定理对当前(变形后)网格求体积;manifold-3d 同时用于示例车架的布尔建模与体积校验。
- **测试**:`node scripts/smoke-worker.mjs`(20 万顶点 Worker 性能与正确性)、`node scripts/smoke-e2e.mjs`(无头 Edge 端到端流程)、`node scripts/screenshot.mjs`(界面截图)。
